## 三、演示视频录制建议（2–3 分钟）

时间轴建议，录屏时用 `publish-win-x64/Tetris.App.exe`：

1. **0:00–0:20**：启动界面，指出分数（十六进制）、最高分、等级、消行、下一个方块。
2. **0:20–1:00**：基本操作——左右移动、顺/逆时针旋转、软降、硬降、消行、升级加速。
3. **1:00–1:30**：`F3` 开 AI 观战（分步档看"旋转 → 平移 → 落点"），再按 `F5` 切极速档，按 `F3` 交回玩家。
4. **1:30–2:10**：**异常场景**（任务书明确要求）：
   - 关闭游戏，删除 `%AppData%\TetrisCourse\highscore.xml`，重新启动 → 侧栏提示"首次运行，暂无存档"并正常开局；
   - 再关闭游戏，把该文件改成乱码，重新启动 → 提示"存档损坏，已忽略"，游戏照常；
   - 重开一局打出高于历史最高分的成绩 → 结束时显示"新纪录！"，重启后最高分仍在。
5. **2:10–2:40**：暂停/继续（`P`）、重开（`F2`）、窗口缩放（证明自适应不闪不变形）。

## 五、复现命令

```bash
dotnet build Tetris.sln          # 编译
dotnet run --project src/Tetris.App

dotnet publish src/Tetris.App -c Release -r win-x64 --self-contained false -o publish
```

存档位置：`%AppData%\TetrisCourse\highscore.xml`
