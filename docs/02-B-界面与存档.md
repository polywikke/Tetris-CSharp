## 三、接口契约

### 3.1 你调用的：`IGameEngine` / `GameState`

```csharp
public interface IGameEngine
{
    GameState State { get; }            // 每帧读，别长期缓存
    void Start(int seed);               // 开新局
    bool Apply(GameCommand command);    // 执行意图；无效返回 false，不抛异常
    void Tick();                        // 推进固定 1/60 秒
}

public enum GameCommand
{
    None, MoveLeft, MoveRight, SoftDrop, HardDrop,
    RotateCw, RotateCcw, Pause, Resume
}

public enum GameStatus { Ready, Running, Paused, GameOver }
```

`GameState` 里你要用的字段：

```csharp
PieceKind?[,] Board;        // Board[x, y]，x 列、y 行、y=0 顶部；null 为空
Tetromino Active;           // 当前方块，Cells 是棋盘绝对坐标
Queue<PieceKind> NextQueue; // 预览队列
int Score, Level, LinesCleared;
GameStatus Status;
GameConfig Config;          // Config.PreviewCount、Config.Shapes[kind].ColorHex
IReadOnlyList<PieceKind> PeekNext(int count);
```

**纪律：界面只读 `GameState`，绝不修改。** 所有改变都走 `Apply`/`Tick`。

### 3.2 你实现的：`IHighScoreStore`

```csharp
public interface IHighScoreStore
{
    string Location { get; }
    HighScoreLoadResult Load();
    bool Save(HighScore record);
}

public sealed record HighScore(int Score, int Level, int Lines, DateTimeOffset AchievedAt);

public enum HighScoreLoadStatus { Ok, Missing, Corrupted, Unreadable }
public sealed record HighScoreLoadResult(HighScoreLoadStatus Status, HighScore? Record, string? Detail);
```

**两个方法都不许抛异常**。这是硬要求，盲测会专门删文件、写乱码、设只读来试。

## 五、任务 1：DAS / ARR 输入（手感的核心）

**现状问题：** 现在直接吃 WinForms 的按键重复，第一次重复延迟约 500ms，长按会一卡一卡。

**规格：**

| 参数 | 值 | 说明 |
|---|---|---|
| 首次移动 | 按下当帧立即生效 | 不能有延迟 |
| DAS（长按延迟） | 180 ms | 按住多久开始连发 |
| ARR（连发间隔） | 40 ms | 连发时每格间隔 |
| 旋转 / 硬降 | **不连发**，一次按键一次动作 | 防止按住狂转 |

**实现建议：**

- 不要在 `KeyDown` 里直接 `Apply`，而是记录"哪些键按着 + 按下的先后顺序"；
- 在 `MainForm.OnFrame` 里、`Tick()` 之前，按累积时间决定这一帧要不要发一个 `MoveLeft/MoveRight`；
- 用 `Stopwatch` 累积毫秒，别用 `DateTime.Now`；
- **暂停、失焦、窗口最小化时清空按键状态**，否则 Alt+Tab 回来方块会瞬移一串；
- 同时按左右：二选一写进报告——
  - 方案 A：最后按下的方向优先（推荐，手感可预期）
  - 方案 B：两个都按 = 不动（"抵消"）

**验收：** 按住左键，方块先走一格，180ms 后开始每 40ms 走一格；松开立刻停；同时按左右行为固定不抖。

## 七、任务 3：存档健壮性（15 分盲测的主战场）

### 7.1 必测的四种场景

| # | 操作 | 期望表现 |
|---|---|---|
| 1 | 删除 `%AppData%\TetrisCourse\highscore.xml` 后启动 | 正常开局，侧栏显示"暂无存档" |
| 2 | 用记事本写入 `这不是XML` 后启动 | 不崩溃，显示"存档损坏，已忽略" |
| 3 | 右键文件 → 属性 → 只读，玩到破纪录 | 游戏继续，提示"存档写入失败，本局成绩未保存" |
| 4 | 用另一个程序独占打开该文件再启动 | 不崩溃、不假死，按"读取失败"处理 |

### 7.2 写入必须原子

顺序不能变：

```
1. 确保目录存在（Directory.CreateDirectory）
2. 写临时文件 highscore.xml.tmp
3. File.Move(tmp, 正式文件, overwrite: true)
4. 失败 → 删临时文件 → 返回 false
```

这样断电/写一半不会留下半个 XML。

### 7.3 界面提示

`MainForm` 已有 `_noticeLabel`，把四种状态映射成四句话（长度控制在 16 字内，别把侧栏撑爆）。

### 7.4 代码检查点

- `Load()` 里 `File.Exists` → `Missing`；
- `XmlSerializer` 反序列化异常 → `Corrupted`；
- `IOException / UnauthorizedAccessException / SecurityException` → `Unreadable`；
- 负分/负等级 → 视为 `Corrupted`；
- **catch 里不要再抛**。
