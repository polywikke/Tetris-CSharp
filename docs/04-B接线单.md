public static IGameRules CreateRules() => new StandardGameRules();

public static IGameEngine CreateEngine(int seed) =>

### ③ F3 开关（`src/Tetris.App/MainForm.cs`）

```csharp
private IPlayerAgent? _agent;

// ProcessCmdKey：和 F2 分支并列
if (keyData == Keys.F3)
{
    _agent = _agent is null
        ? new HeuristicAgent(_engine.State.Config, AppBootstrap.CreateRules())
        : null;
    _agent?.Reset();
    return true;
}

// OnFrame：放在 _engine.Tick() 之前
if (_agent is not null && _engine.State.Status == GameStatus.Running)
{
    _engine.Apply(_agent.NextCommand(_engine.State));
}
```

## 三、四个坑

1. **`Start()` 会换掉 `State` 对象。** 每帧重新 `_board.State = _engine.State`，别把引用缓存起来跨局用（`IGameEngine.State` 的注释就是这么写的）。
2. **AI 接管期间要吞掉玩家按键。** 在 `ProcessCmdKey` 里如果 `_agent is not null`，方向键/空格直接返回 `true`，否则人和 AI 会抢同一块方块。
3. **规则实例共享一个。** `StandardGameRules` 是无状态的，共享绝对安全；但统一走 `CreateRules()`，将来它一旦有状态也不会出错。
4. **`seed` 现在是 `Environment.TickCount`，每局都不同。** 录演示或复现 bug 时换成固定值（如 `20261029`），方块序列就完全可复现。

## 五、AI 可视化（可选加分项）

`HeuristicAgent` 同时实现了 `IPlayerAgentDebug`，所以热力图不用额外算：

```csharp
var debug = _agent as IPlayerAgentDebug;   // 允许为 null
// debug.Candidates：本次考虑过的全部落点（Score/ClearedLines/Holes 都在里面）
// debug.Chosen：最终选中的那个
```

`BoardView` 里按 `Candidate.X/Y/Rotation/Kind` 画半透明方块，颜色按 `Score` 归一化（绿→红），`Chosen` 加亮边。候选最多几十个，60fps 画得动；AI 关闭或 `Candidates` 为空时别画。
