## 三、接口契约（你实现的部分）

### 3.1 `IGameRules` —— A 实现，C 调用

```csharp
namespace Tetris.Core;

public interface IGameRules
{
    bool Collides(GameState state, Tetromino piece);
    int  DropDistance(GameState state, Tetromino piece);
    bool TryMove(GameState state, int deltaX);
    bool TryRotate(GameState state, int direction);   // +1 顺时针，-1 逆时针
    int  LockActive(GameState state);                 // 返回消掉的行数
}
```

| 方法 | 语义 | 失败时 |
|---|---|---|
| `Collides` | 该姿态是否与墙/地/已固定方块重叠 | 纯查询，不改状态 |
| `DropDistance` | 从当前位置竖直下落还能掉几格（0 = 已贴底） | 纯查询 |
| `TryMove` | 左/右移一格 | 被挡返回 `false`，**状态不变** |
| `TryRotate` | 旋转并依次尝试踢墙偏移 | 全失败返回 `false`，**状态不变** |
| `LockActive` | 固定当前块 → 消行 → 计分 → 升级 | 不生成新块（那是引擎的事） |

**硬性要求：**

- 五个方法都**不许抛异常**；
- 不依赖时间、随机数、界面；同样输入必然同样输出；
- 只改 `state`，不改 `GameConfig` / `PieceShapes`。

### 3.2 `IGameEngine` —— A 实现，B 调用

```csharp
public interface IGameEngine
{
    GameState State { get; }
    void Start(int seed);
    bool Apply(GameCommand command);
    void Tick();
}
```

| 方法 | 语义 |
|---|---|
| `Start(seed)` | 开新局：`随机源.Reseed(seed)` → 清盘 → 重建 7-bag → 出第一个方块 → `Status = Running` |
| `Apply(cmd)` | 执行意图；状态不允许（暂停/结束/无效）返回 `false`，**不抛异常、不改状态** |
| `Tick()` | 推进固定 1/60 秒：重力累积够了就下落一格或锁定 |
| `State` | 界面每帧读它，**只读** |

## 四、你需要知道的共享类型

```csharp
public sealed class GameState
{
    GameConfig Config;
    int Width, Height;                 // 12, 16
    PieceKind?[,] Board;               // Board[x, y]，null 为空
    Tetromino Active;                  // 当前下落的方块（永不为 null）
    Queue<PieceKind> NextQueue;        // 预览队列
    int Score, Level, LinesCleared;
    GameStatus Status;                 // Ready/Running/Paused/GameOver
    long Frame;
    GameState Clone();
    int SpawnX();                      // (Width - 4) / 2
    bool IsInside(int x, int y);
    bool IsRowFull(int y);
    void ClearBoard();
}

public sealed class Tetromino                 // 不可变
{
    PieceKind Kind; PieceShape Shape;
    int X, Y, Rotation;                       // 4×4 包围盒左上角
    IReadOnlyList<CellPos> Cells;             // 棋盘绝对坐标
    Tetromino With(int? x = null, int? y = null, int? rotation = null);
}

public sealed class GameConfig
{
    int BoardWidth, BoardHeight, PreviewCount, LevelUpLines;
    IReadOnlyList<int> GravityMsByLevel;
    IScoreRule ScoreRule;                     // 默认 100 × k
    IReadOnlyDictionary<PieceKind, PieceShape> Shapes;
    int GravityMsFor(int level);
}
```

坐标：**`[x, y]`，x 是列、y 是行、y = 0 在顶部**。

## 五、实现规格（按这个来，跟 B/C 的约定）

### 5.1 生成

- 位置：`X = state.SpawnX()`（12 列时是 4），`Y = 0`，`Rotation = 0`；
- 生成后如果 `Collides` → `Status = GameOver`。

### 5.2 碰撞

```
遍历 piece.Cells：
  x < 0 或 x >= Width   → 碰撞
  y >= Height           → 碰撞
  y >= 0 且 Board[x,y] 有值 → 碰撞
  y < 0                 → 忽略（允许探出顶部）
```

### 5.3 旋转踢墙（简化 SRS，够用且好讲）

依次尝试偏移，第一个不碰撞的生效：

- JLSTZ：`(0,0) (-1,0) (+1,0) (-2,0) (+2,0) (0,-1)`
- I：`(0,0) (-2,0) (+2,0) (-1,0) (+1,0) (0,-1)`

报告里写明"简化版：只做一档踢墙，不做完整 SRS 表"——这是**主动的设计取舍**，比含糊带过更好。

### 5.4 锁定与消行

```
LockActive(state):
  1. 把 Active.Cells 写进 Board（y >= 0 的才写）
  2. 从下往上找出所有满行，记录行号
  3. 删除这些行，上面的行整体下移（推荐"写指针从底往上搬"的写法，O(H×W)）
  4. cleared = 行数
  5. Score += Config.ScoreRule.ScoreFor(cleared, 升级前的 Level)
  6. LinesCleared += cleared
  7. Level = LinesCleared / Config.LevelUpLines + 1
  8. return cleared
```

**不要在 `LockActive` 里生成新方块**——C 的 AI 会克隆状态反复调用它，生成新块会污染推演。

### 5.5 重力与锁定（`Tick`）

```
if (Status != Running) return;
Frame++;

_accumulatorMs += 1000.0 / 60.0;
if (_accumulatorMs < Config.GravityMsFor(Level)) return;
_accumulatorMs = 0;

// 能下就下，不能下就锁定
if (!Collides(state, Active.With(y: Active.Y + 1)))
    Active = Active.With(y: Active.Y + 1);
else
    LockAndSpawn();
```

`LockAndSpawn()`：`Rules.LockActive` → 取队列下一个 → 生成 → 若碰撞则 `GameOver`。

### 5.6 7-bag 与预览队列

- 一个 bag 装 7 种各一个，Fisher-Yates 用 `IRandomSource.Next` 洗牌；
- 取空就重新装一袋；
- 每次生成后把 `NextQueue` 补到 `PreviewCount + 1` 个，界面才能显示"下一个"。

### 5.7 命令处理

| 命令 | 行为 |
|---|---|
| `MoveLeft/Right` | `TryMove(±1)`，被挡返回 false |
| `SoftDrop` | 能下一格就下（不计分）；不能下返回 false，**不锁定** |
| `HardDrop` | 一直下到底，然后立即 `LockAndSpawn` |
| `RotateCw/Ccw` | `TryRotate(±1)` |
| `Pause` | 仅 `Running` 时可暂停 |
| `Resume` | 仅 `Paused` 时可继续 |
| `None` | 直接 false |

`Status != Running` 时，除 `Resume` 外一律返回 `false`。

### 5.8 开局（`Start`）

```
_random.Reseed(seed);
_state = new GameState(_config) { Status = Running };
_bag.Clear();
SpawnNext();          // 内含补队列与碰撞判负
_accumulatorMs = 0;
```

`State` 引用会变，界面每帧重新取，不要缓存旧对象。

public sealed class GameEngine : IGameEngine
{

        _random = random ?? throw new ArgumentNullException(nameof(random));

    public void Start(int seed) { /* 见 5.8 */ }

    private void SpawnNext() { /* 补队列 → 出队 → 生成 → 判负 */ }

    private void LockAndSpawn() { /* LockActive → SpawnNext */ }
}
